# Familia Brío — archivos de trabajo

Logotipos canónicos, todos en SVG autónomo con contornos:

| Positivo | Negativo | Uso |
| --- | --- | --- |
| `brio-rol.svg` | `brio-rol-reverse.svg` | Marca de autor |
| `brio-sistema.svg` | `brio-sistema-reverse.svg` | Sistema de juego |
| `brio-online.svg` | `brio-online-reverse.svg` | Aplicación online |
| `ruido.svg` | `ruido-reverse.svg` | Nombre independiente de la herramienta |
| `dados.svg` | `dados-reverse.svg` | Nombre de una herramienta futura; exploración |
| `brio.svg` | `brio-reverse.svg` | Firma de procedencia separada en la web |

`index.html` muestra los cinco logos, las versiones negativas, tamaños reales y una firma web separada. Los SVG de Ruido y Dados no llevan firma añadida.

No hay variantes pequeñas alternativas: los mismos dibujos conservan lectura a los tamaños de referencia. Se han recortado las cajas sin alterar las proporciones. La guía completa de dibujo, procedencia y uso está en `../../docs/BRAND-ARCHITECTURE.md`.

`archive/by-brio/` conserva la exploración anterior; no forma parte de la entrega canónica.

El descriptor final de la aplicación es «online»; su dominio acordado es `online.briorol.com`. La prueba anterior con «salas» queda en `archive/salas/`.
